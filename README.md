# Portfolio-style Landing (inspired concept)

Одностраничный сайт в стиле современного креативного портфолио (hero, кейсы, услуги, процесс, форма заявки).

## Запуск

Откройте `index.html` в браузере.

## Структура

- `index.html` — разметка лендинга.
- `styles.css` — визуальный стиль, сетки, адаптив.
- `script.js` — мобильное меню, reveal-анимации, обработка формы.

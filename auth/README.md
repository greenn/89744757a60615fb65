# Auth integration patch (for existing portfolio project)

Этот репозиторий сейчас не содержит исходников действующего сайта (в git есть только `README.md`, `LICENSE`, `.gitignore`).

Чтобы не создавать новый проект с нуля, я подготовил **минимально-инвазивный набор файлов** для встраивания авторизации в существующий Next.js/React-портфолио проект:

- публичные страницы остаются публичными;
- `/account` защищён и редиректит гостей на `/login`;
- реализованы формы `/login`, `/register`, `/forgot-password`;
- пароли хэшируются (`bcryptjs`);
- сессия через JWT в `httpOnly` cookie;
- хедер переключает UI гостя/авторизованного.

## Что добавить в существующий проект

1. Скопировать файлы из этой папки в ваш рабочий `src`/`app` (или адаптировать пути).
2. Подключить реальную БД вместо in-memory хранилища (`auth/lib/user-store.ts`).
3. Добавить переменные окружения:
   - `AUTH_JWT_SECRET`
4. Установить зависимости:
   - `bcryptjs`
   - `jose`

## Поток авторизации

1. **Регистрация**: POST `/api/auth/register` → валидация → hash пароля → создание пользователя.
2. **Вход**: POST `/api/auth/login` → проверка email/пароля → выдача JWT cookie.
3. **Проверка сессии**: сервер читает cookie `auth_token` и валидирует JWT.
4. **Доступ к `/account`**: middleware + server-side guard делают редирект на `/login`.
5. **Выход**: POST `/api/auth/logout` удаляет cookie.
6. **Восстановление пароля**: POST `/api/auth/forgot-password` (без утечки существования email).
